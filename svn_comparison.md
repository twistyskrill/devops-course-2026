1. В Git ветка дешёвая, потому что это просто указатель на коммит. Файлы не копируются, поэтому ветки создаются быстро.
   В SVN ветка считается дороже, потому что работа идёт через центральный сервер. Хотя SVN тоже не копирует все файлы буквально, пользоваться ветками там обычно тяжелее: нужны сетевые операции, сложнее слияния и переключения.
2. Без интернета в SVN обычно нельзя сделать коммит, потому что коммит сразу записывается в центральный репозиторий на сервере. Если связи с сервером нет, новую ревизию создать нельзя.
3. SVN может быть удобнее, если нужен строгий центральный контроль, доступ только к отдельным папкам, работа с большими бинарными файлами или блокировка файлов. Ещё SVN подходит для старых enterprise-проектов, где вся инфраструктура уже построена вокруг него.
